Live site: https://dhaifallahms-source.github.io/

Six data analysis projects (SQL Server, Python, Power BI, DAX). Each one goes from problem to approach to decision to a quantified impact, with assumptions stated.

| Project | Tools | Headline finding |
|---|---|---|
| Olist: late deliveries and reviews | SQL Server (T-SQL) | 8.11% of delivered orders arrive late; late orders average 2.57 stars vs 4.29 on time |
| Olist: late-delivery risk model | Python (pandas, scikit-learn) | Riskiest 10% of orders are late 27.9% of the time vs 1.5% for the lowest 10%; ROC-AUC 0.756, 0.675 on future orders |
| Customer churn | Power BI, DAX | 47.37% churn; about 71% beyond 15 days of payment delay |
| E-commerce revenue | Power BI, DAX | Discounts up to 30% sold no extra units per order |
| HR attrition risk | Power BI, DAX | Overtime staff leave at 30.5% vs 10.4% |
| Sales profitability | Power BI, DAX | 5.6x seasonal gap; negative margin at 61%+ discount |

Code and dashboards: https://github.com/dhaifallahms-source

All projects use public Kaggle datasets. Dollar figures are scenario estimates, not realized results.
